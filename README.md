# geopolars_notebook
Repositář pro semestrální projekt do předmětu "Prostorová data v Pythonu" 

## Použité knihovny
Polars: Sloupcový DataFrame s využitím Apache Arrow pro agregaci a filtrování.
GeoPandas: Standard pro čtení prostorových dat (shapefiles) a transformaci souřadnicových systémů.
PyArrow: Pro bezkopírovací přenos dat mezi GeoPandas a Polars.

## Použitá data
V praktické ukázce jsou použita vektorová polygonová data Natural Earth – Admin 0 Countries (měřítko 1:110m). Data obsahují generalizované hranice států světa.

## Obsah repozitáře
* `geopolars_notebook.ipynb` - Jupyter Notebook s teoretickým úvodem a plně funkční praktickou ukázkou.
